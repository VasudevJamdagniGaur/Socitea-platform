# SociTea immersive site (Morphos shell)

Black-background SociTea experience with working routes for Features, Discover, Create, Extension, and Download.

## Run

From the repo root:

```bash
npm run morphos
```

Or inside this folder:

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:5180](http://127.0.0.1:5180).

## Routes

- `/` — original Morphos scroll experience (iframe at `/experience/`)
- `/features`
- `/discover`
- `/create`
- `/extension`
- `/download`
- `/404`

## Downloads / extension

Configure verified URLs in `.env` / `.env.local` using `.env.example`. Empty values keep **Coming Soon** states.
